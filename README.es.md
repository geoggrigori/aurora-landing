## Acerca de

**Aurora** es una landing page de producto animada y pulida, mostrando craft de UX/UI y front-end: tema claro/oscuro con toggle, animaciones de scroll-reveal, selector de precio mensual/anual y un layout totalmente responsivo y accesible.

## Destacados de UX/UI

- **Dark mode** con toggle, persistido en `localStorage`, aplicado antes del paint para evitar flash (FOUC).
- **Scroll-reveal** vía `IntersectionObserver` (sin librería de animación).
- **Pricing interactivo** con alternancia de facturación mensual/anual.
- **Sensibilidad de design system**: espaciado consistente, acentos en degradado, estados hover, tipografía equilibrada.
- Responsivo de mobile a desktop; markup semántico y accesible por teclado.

## Uso

```bash
npm install
npm run dev      # http://localhost:3000
```
